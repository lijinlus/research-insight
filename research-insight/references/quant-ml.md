# Quant / ML：能改变研究判断的检查

仅用于金融预测、因子、策略或相关 ML 研究的证据设计，不提供交易建议。按实际数据和协议检查，不把这些项目当作已发生的问题。

## 信息在决策时真的可得吗

写出特征观测、发布时间、预处理拟合、决策、成交、收益区间和标签完成的时间线。交易日期不等于数据可用日期；财报修订、新闻抓取、成分股和退市信息尤其要检查 point-in-time 来源。

标签跨度为 h 时，用实际交易时点和标签完成时间确定训练样本何时能进入模型。横截面因子的“有效性”可能到整组未来收益实现后才能计算；不能把日期为 t 的因子表现当作 t 时刻已知。

全样本标准化、Rank-Gaussian 映射、残差化、特征筛选和调参都可能跨越切分边界。检查每一步拟合所用样本和时间；OOF 也必须符合任务的时间与信息约束，不能因名称含 OOF 就视为安全。

按实际使用的信息判定，不能仅凭变换名称认定泄漏。在决策时点用当时确实可得的股票池和特征做横截面排序/标准化，可以符合信息约束；把未来日期的数据用于拟合历史变换则是另一回事。若残差化目标或参考变量含尚未实现的收益，也要检查其标签完成时间。

## 比较是否回答了研究问题

- 保持预测目标、股票池、历史窗口、信息集、评估时间段和调参机会尽量一致；不能把数据优势误称算法优势。
- 新机制应面对有竞争力的简单对照：如持久性、历史滚动统计、合理正则化模型、同信息与预算的筛选/集成。具体选择取决于任务，不机械要求某套模型。
- LLM 因子/Agent 研究检查 API 版本、可见时间、新闻或收益是否被后验泄漏、总 token/调用次数/重试预算、失败请求如何计入。角色提示带来新信息时，不能仅把差异归因于协作。
- 交易结论需要可交易性、换手、成本、成交滞后与约束；纯预测结论可以不声称可部署收益，但要明确其范围。

跨市场无标签适应时，明确是离线访问整段目标期，还是只用当前可得的历史；没有收益标签也可能访问未来分布信息。LLM因子闭环中，评分器会诱导候选分布改变：用封存时期检查其排序是否仍有效，并与等总调用预算的单轮生成/简单筛选比较。多个Agent读取同一新闻或同一回测结果，不构成多份独立确认。

## 统计与选择偏差

区分跨股票的横截面测量与跨时间的独立重复。IC/RankIC 的逐日序列可能相关，重叠标签也使收益相关；不把股票数直接当独立样本量。按实际依赖选择区间或检验方案，不能在未知依赖结构时硬套一个方法。

记录因子、股票池、窗口、K、超参、seed、方法变体和指标的搜索范围。反复在同一个测试期筛选会把测试期变成验证期。探索所得结论需要后续隔离时间段或其他适当的确认性检查；显著性检验不能自动消除选择偏差。

新闻改写、同一事件多报道、相似因子表达式和同一基础任务的多轮尝试可能共享来源；按事件/表达式家族和时间识别依赖。新闻“信息增益”若用人类评分、文本novelty或LLM memory更新代理，不等于已估计互信息、unique/redundant/synergistic信息或增量价格发现；需分别定义、验证。

区分平均改善、跨市场/时期稳定性、极端条件失效和实际量级。CSI 市场上的结果不能直接推出 S&P 500 也成立；若要解释迁移失败，先检查数据实现、覆盖、目标、成本和分布差异，再提出机制假设。

## 一个优先的实验问题

若主张是“延迟反馈导致现有筛选/预测失效”，先比较严格保持同一数据、切分、选择预算的可观测反馈设定，并用明确标注为不可部署的及时反馈 oracle 帮助定位差距。oracle 用于诊断，不能混入可交易结果。该比较仍未必识别唯一根因，需检查历史窗口、目标构造与市场状态等竞争解释。
