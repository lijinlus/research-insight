# 研究操作库：从材料产生可检验的主线

此文件最初从用户提供的 [Story Is All You Need 二手文章](https://mp.weixin.qq.com/s/mnU8PE-6DZ38rJqHeOiSfQ) 提炼候选操作，现结合[35篇原文分析](paper-library/index.md)修订。它们帮助产生研究方向，不是经统计验证的获奖规律，也不是所有好研究必须满足的清单；二手文章的技术概括不作为证据。

## 怎么使用

先识别已有材料：观察到的失败、未经检验的默认假设、尚无解释的规律、测量盲区、真实应用约束，或多套方法之间的共同结构。选择最有依据的一两种操作；没有明显匹配时保留原问题，不强行追求反直觉或根因故事。

探索阶段可形成少量候选，每个说明：**触发材料 → 可能的知识增量 → 区分性预测 → 最便宜的下一步 → 当前未知**。比较它们的价值、近邻重合与验证成本后推荐先做一个。无论新主线是否成立，都应说明相应结果会如何改变判断。

已有结果时，按证据选择主线；若想提出新解释，明确标为探索假设。不要为了符合某种范式，事后挑选窗口、任务或指标。

## 1. 诊断失败：把“无效”拆成可区分的原因

**适用材料**：可重复的失败或条件差异，且已初步检查实现与评估是否正确。

**研究操作**：列出竞争解释，寻找它们预测不同的条件；先诊断，再判断是否值得设计针对性方法。新方法有效与根因被识别是两个不同主张。

**候选主张**：在条件 C 下，变量 Z 的变化解释了部分失效；针对 Z 的干预改变了预期行为。若只能发现关联，就保留为有边界的现象主张。

**关键验证与图**：控制其他条件的干预、替代解释对照；图展示效果是否随目标变量按预测变化。单独移除模块后性能下降不够。不要未经区分就称“唯一根因”。

**怎样形成候选**：[Lychee-FD §3与Appendix D](paper-library/22-lychee-fd.md)将冲突定位到层与目标，再做梯度更新干预；[STEER §§3–5](paper-library/29-steer.md)从变化量解释旧技巧，再提出选择性权重。可先把“总体不好”分成阶段/位置/样本条件，找预测分叉；无需先设计完整系统。

## 2. 检验默认假设：找出优势成立的条件

**适用材料**：有来源可定位的惯常设计或明确假设，例如更多上下文、更多自由度、更多交互可能更有用。

**研究操作**：精确定义假设，并在信息和预算合理可比时改变它的强度或适用条件。先确认这确是已有工作的假设，不把夸张口号当作领域共识。

**候选主张**：假设 A 的收益依赖条件 C，在 C 改变时出现成本或失效；替代设计解决其中一部分。

**关键验证与图**：假设强度/环境条件与效果的曲线、正反例、预算匹配。只找到一个反例可以界定边界，未必能推翻整套方法。结果符合常识时也可有价值，不制造反直觉。

**怎样形成候选**：[Flexibility Trap §§3–5](paper-library/05-flexibility.md)拆开并行与任意顺序，并区分训练/推理阶段。面对被捆绑的两个优点，问它们是否必须共存，尝试只在必要阶段施加约束，而非全面否定某架构。

## 3. 解释规律：提出与真实操作相连的形式问题

**适用材料**：稳定的经验规律、可证明的能力差异，或尚未解决的算法/复杂度问题；理论研究也可直接从形式问题出发。

**研究操作**：明确对象、假设、比较类和量词，寻找能推出可区分预测的简化模型或命题。说明形式设定如何对应实际方法，以及哪里不对应。

**候选主张**：在假设 A 下，操作 M 具有某能力、边界、复杂度或误差性质；这给出对条件 C 的预测。不要为装饰方法增加无关引理。

**关键验证与图**：证明或明确尚未证明的命题、反例与边界；涉及经验解释时，用能区分理论预测的实验搭桥。表达能力不自动推出可学习性、优化效率或现实任务表现。

**怎样形成候选**：[Model Change §§3–6](paper-library/08-model-change.md)由组合操作反例提出新对象与相容条件；[High-Accuracy Sampling §§1/3/4](paper-library/06-sampling.md)固定oracle、精度、误差距离后找复杂度缺口。先确认要证的是存在性、表示效率还是算法代价，再找关键子命题。

## 4. 检查测量：把未测到的能力变成可验证问题

**适用材料**：现有分数与实际能力不一致、被平均值掩盖的失败，或现有协议没有覆盖的必要条件。

**研究操作**：先定义要测量的能力和用途，再设计任务、对照和指标。检查评分器是否可靠、是否存在捷径，是否仅因任务更难而普遍降分。

**候选主张**：现有测量不能区分能力 X 与混杂 Y，新协议在明确范围内改善这种区分。

**关键验证与图**：已知正负例、匹配难度的对照、适当的人工或独立核验；图揭示旧分数掩盖了哪类行为。新基准让模型变差或改变排名，本身不证明测得更准；避免挑选仅有利于自家方法的任务。

**怎样形成候选**：[Forms–Meanings §4.1](paper-library/28-forms-meanings.md)用旧度量保持不变的form-only置换检验新敏感性；[Imperfective NLI Table 3](paper-library/15-imperfective.md)用互补组发现修复也会伤害正确判断。先列新尺子应对哪些变化敏感、对哪些变化不敏感，再造最小对。

## 5. 引入真实约束：让用途改变问题定义

**适用材料**：离线设定与实际使用存在差距，例如反馈延迟、标注稀缺、跨地区变化、失败代价或预算限制。

**研究操作**：将具体约束写进数据、目标或协议，说明它如何改变已有方法的适用性。真实用途可以贡献重要任务与资源，不必夸成全新的通用机制。

**候选主张**：在约束 C 下，原来的比较/方法不足以回答需求，新协议或方法在对应效用上带来可检查的增量。

**关键验证与图**：约束存在的证据、可行的替代方案、效用与失败代价；图展示真实约束怎样改变结论。若只测了代理指标，说明它与实际用途的距离，不声称已经产生社会影响或部署收益。

**怎样形成候选**：[PolyGloss §§1/3/8](paper-library/31-polygloss.md)从用户纠错、标签习惯和资源条件产生需求；[CAR-bench §3.2](paper-library/32-car-bench.md)将做不到、需查证写成任务。先画使用者的决策与反馈流程，找“现有指标不错却不能用”的具体环节。

## 6. 寻找共同结构：验证统一带来的实际增量

**适用材料**：多个任务共享结构，或多套组件有重复计算、冗余假设和难以维护的接口。

**研究操作**：提出一个共同对象、表示或操作，说明原来的多个任务如何由它得到，以及统一引入了哪些代价。

**候选主张**：共享结构 M 在条件 C 下覆盖任务集合 T，并改善一致性、质量、成本、可扩展性或实现复杂度中的明确一项。

**关键验证与图**：逐任务强基线、同信息与预算的比较、迁移或负迁移、质量与成本边界。一个 API 或更少模块不自动构成知识增量；统一也可能牺牲专项能力。

**怎样形成候选**：[D4RT §§2–4](paper-library/01-d4rt.md)统一时空点查询，再映射不同几何任务；[ViLL-E §§3/5](paper-library/33-vill-e.md)从能力版图补上生成与embedding接口。先找共同原语/缺失能力，再决定哪些部分值得共享；允许任务特定读出与后处理，但将成本计入。

## 从研究操作到论文主线

选定候选后形成一个论证骨架：

> 已知什么 → 缺口或条件差异是什么 → 新主张是什么 → 哪项证据支持哪条连接 → 什么情况下不成立。

若证据缺失，交付缺口和补证方案。若只是段落顺序不清，可重排骨架；不能用语言强化替代实验或证明。无需硬凑完整的“现象—根因—方法”三段式。

## 原文案例与边界示例

原文结构与论证细读已整理为 [35 篇案例索引](paper-library/index.md)。逐篇记录阅读范围、来源版本、主张—证据关系及适用边界；这是用户文章推荐集合，不是全年全部获奖论文。选择案例时看研究问题和证据类型，不强行按六类给每篇贴唯一标签。

- [Local Attention](paper-library/17-local-attention.md)：可借鉴形式预测与实验之间搭桥；不能把全局与局部的互补性概括成纯局部普遍更好。
- [LLMs Get Lost](paper-library/04-lost.md)：可借鉴可比协议与多维指标；其模拟设定和分位数指标定义不应在迁移时省略。
- [ViLL-E](paper-library/33-vill-e.md) 与 [LLM2CLIP](paper-library/12-llm2clip.md)：多阶段设计也可以有清楚主线。应检查每阶段解决什么问题及其成本，不以组件数量判断贡献。
